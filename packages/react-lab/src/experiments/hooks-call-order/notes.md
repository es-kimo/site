# 훅은 이름이 아니라 호출 순서로 슬롯에 매핑된다

## 실험 방법

1. 체크를 끈 채로 마운트한다.
2. 체크를 켠다.
3. "다시 마운트"를 누른다 (체크는 켠 채로).

## 관찰

- 1 →
- 2 →
- 3 →

## 왜 그런가

Fiber는 컴포넌트마다 훅 노드의 단일 연결 리스트를 들고 있고, 렌더 중 훅이 호출될 때마다
리스트를 앞에서부터 하나씩 소비한다. 변수 이름은 어디에도 기록되지 않는다.

  "렌더마다 순서가 같기만 하면 된다"가 진짜 규칙이라는 걸 보여준다.
